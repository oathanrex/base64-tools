# Base64 Tools Hub

A comprehensive single-page web application for all Base64 encoding/decoding operations. 35+ tools in one place!

![Base64 Tools Hub](https://img.shields.io/badge/Tools-35%2B-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![No Dependencies](https://img.shields.io/badge/Dependencies-None-orange)

## Features

- **35+ Base64 Tools** - Everything you need for Base64 operations
- **Dark/Light Theme** - Easy on the eyes, your preference is saved
- **Mobile Responsive** - Works perfectly on all devices
- **No Dependencies** - Pure HTML, CSS, and JavaScript
- **Offline Capable** - Works without internet after first load
- **Keyboard Shortcuts** - Power user friendly

## Tools Categories

### Text Tools
- Text to Base64 Encoder
- Base64 to Text Decoder
- URL-Safe Base64 Encoder/Decoder
- Live Encoder/Decoder

### File Tools
- File to Base64
- Base64 to File
- Batch File Encoder

### Image Tools
- Image to Base64
- Base64 to Image
- Image to CSS Background
- Image to HTML IMG Tag
- Batch Image Encoder

### Audio/Video Tools
- Audio to Base64
- Base64 to Audio
- Video to Base64
- Base64 to Video

### Document Tools
- PDF to Base64
- Base64 to PDF
- JSON to/from Base64
- XML to Base64
- CSV to Base64

### Developer Tools
- Data URI Generator
- MIME Type Detector
- Base64 Validator
- Size Calculator
- Base64 Diff Tool

### Security Tools
- Base64 + MD5/SHA256 Hash
- JWT Decoder
- Basic Auth Generator

### Utility Tools
- Bulk Encoder/Decoder
- Base64 to/from Hex
- Binary to/from Base64

## Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + K` | Open search |
| `Ctrl + Enter` | Execute encode/decode |
| `Ctrl + Shift + C` | Copy output |
| `Ctrl + D` | Toggle theme |
| `Ctrl + L` | Clear all |
| `Escape` | Close modal / Go back |
| `?` | Show shortcuts help |

## Installation

1. Clone or download this repository
2. Open `index.html` in your browser
3. That's it! No build process required.

For local development with ES6 modules:
```bash
# Using VS Code Live Server extension
# Or any local server like:
npx serve .
# or
python -m http.server 8000
```
